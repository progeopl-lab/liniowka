PRO GEO – Projekt robót geologicznych (PRG)
Samodzielny projekt aplikacji webowej (tylko moduł 7 – bez kalkulatorów 1–6).

JAK PRZENIEŚĆ DO NOWEGO PROJEKTU W GOOGLE AI STUDIO:
1. Rozpakuj tę paczkę ZIP na komputerze do osobnego folderu.
2. Utwórz nowe puste repozytorium na GitHubie (np. pro-geo-prg).
3. Na GitHubie kliknij „uploading an existing file” i wrzuć całą zawartość rozpakowanego folderu (pamiętaj o plikach ukrytych jeśli potrzebne, choć wystarczy zawartość wraz z package.json, index.html, server.ts, metadata.json, tsconfig.json, vite.config.ts, src/, public/).
4. W Google AI Studio Build kliknij znak „+” przy polu tekstowym → Import from GitHub → wybierz nowe repozytorium.
5. (Opcjonalnie dla opisu geologicznego AI w rozdziale 3): w Settings → Secrets nowego projektu dodaj klucz GEMINI_API_KEY.
